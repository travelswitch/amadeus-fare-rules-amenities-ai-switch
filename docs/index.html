Amadeus NDC Fare Rules & Amenities AI Switch is a self-hosted API and admin UI that takes the fare rules and fare-family benefit text exactly as they arrive in Amadeus NDC responses and returns clear, multilingual summaries, classified amenity cards, friendly fare-family names and a chat that answers the questions travellers actually ask, using the LLM provider you choose.

The problem

Amadeus NDC passes fare rules and benefit lists through as-is. Travellers can't read them.

In Amadeus NDC flows the fare-family names, amenity lists and fare-rule text arrive exactly as the airline supplies them. There is no short version, no length control and no standardisation across carriers. That is by design and compliant with the NDC standard, so the integrator has to solve it.

How it works

Four calls from an Amadeus NDC response to a happy traveller.

Each endpoint takes the text exactly as Amadeus returned it and gives back something a person can read. Identical inputs are served from cache, so repeated content never reaches the model twice.

1

Fare rules summary

POST the fare-rules text from the Amadeus NDC response to /api/v1/fare-rules/summary. Get Markdown mini rules: a table on desktop, compact sections on mobile, in any language.

2

Amenities

POST the fare-family benefit lines to /api/v1/amenities/summary. Duplicates merge, each benefit is classified, limits are kept as details, and it is translated.

3

Fare names

POST codes such as ECOLITE to /api/v1/amenities/fare-names and show "Economy Lite" on the fare card.

4

Chat

Stream answers over Server-Sent Events from /api/v1/fare-rules/chat/stream. Segment-aware and date-aware across the whole itinerary.

Everything included

Production-grade from the first docker compose up.

Fare rules summary

Cancellation, change, refund and no-show conditions as a clean table or mobile sections. Uppercase ATPCO text decoded, amounts and time windows kept exact.

Amenities

Raw fare-family benefit lists in; de-duplicated, classified, translated cards out. Baggage, seat, lounge, meal, miles, each with limits kept as details.

Chat

"Can I change the return the day before?" Streamed answers over one or many segments, grounded only in the fare rules provided.

Fare-family names

ECOLITE becomes "Economy Lite", BUSIFLEX becomes "Business Flex". Cached per code and language.

Any LLM, switch any time

OpenAI, Azure OpenAI, Anthropic Claude, Google Gemini, Groq or AWS Bedrock. Test the connection from the UI; keys are encrypted at rest.

Multilingual

Arabic, Urdu, French, German, Hindi, Chinese and more. The response language is a request parameter; RTL scripts are handled.

Cache-first and deterministic

Temperature 0 and a content-digest cache: the same Amadeus text always gives the same answer, in milliseconds and at zero token cost after the first time.

Admin UI

Provider setup, API keys, usage analytics, data stores and a playground for all four endpoints.

Editable prompts

Tune every prompt from the UI with placeholder validation and a live preview against sample data. Reset to default any time.

Secure by default

Hashed API keys, encrypted credentials, CSRF-guarded sessions, rate limiting, request ids, non-root container, health probes.

Your data stores

Ships with Postgres and Redis, or point it at your own from the UI. Schema migrates itself; config carries over.

Usage analytics

Requests, tokens, latency and cache hit rate per day, per endpoint, per model and per API key, so cost stays visible.
